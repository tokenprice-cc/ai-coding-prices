- 中转站倍率读自各站公开的定价接口（New API、Sub2API、ai-transit 披露等），每小时采集；Claude / GPT / Gemini / Grok 低于 0.1x、其他模型低于 0.05x 的体验或引流分组不算，可用率低于 95% 的站不进榜。

- 卡网价只算有货的标准商品；官方价来自 App Store 和官网的公开价格。
